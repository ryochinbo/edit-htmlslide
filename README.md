# HTMLスライドエディター

`slides/` 以下のHTMLスライドを、PowerPointのようにブラウザ上で直接編集するツールです。

## 起動

`エディター起動.bat` をダブルクリックします。ブラウザで http://localhost:5180/editor/ が開きます。
終了するときは黒いウィンドウを閉じます。

コマンドで起動する場合は `node server.js` を実行します（Node.js 18以上。追加パッケージは不要）。

## ファイルを開く

ツールバーの「📂 開く」（Ctrl+O）から、パソコン内の好きな場所のHTMLを選べます。

- **最近使ったファイル**：前に開いたファイルにすぐ戻れます。起動時は最後に開いたファイルが自動で開きます
- **場所／ドライブ**：slides フォルダ・デスクトップ・ドキュメント・ダウンロード・各ドライブからフォルダをたどれます
- **パス入力**：フォルダやHTMLのパスを貼り付けて Enter（エクスプローラーの「パスのコピー」の値もそのまま使えます）
- **Windowsのダイアログで選ぶ…**：いつもの「開く」画面で選べます

画像などは相対パスで読み込むので、HTMLと `assets` フォルダなどは元の位置関係のまま置いてください。
保存・PDF・画像の出力先は、開いたHTMLと同じフォルダです。

## できること

- **選択**：クリックで選択。選択中の要素をもう一度クリックすると内側の要素を選択、Escで外側へ
- **移動・サイズ変更**：ドラッグで移動（スナップ付き。Shiftで軸固定、Altでスナップ無効）、8方向ハンドルでサイズ変更、矢印キーで1px（Shiftで10px）移動
- **文字**：ダブルクリック（またはEnter）で文字を直接編集。文字の一部を選択して色・サイズ・太字などを変更可能
- **書式**：文字色、文字サイズ、太字・斜体・下線、揃え、行間、フォント、塗り、枠線、角丸、不透明度、回転
- **挿入**：テキストボックス、四角形、角丸四角形、楕円、三角形、直線、矢印、画像（`assets/uploads/` に保存）
- **スライド**：追加（空白・タイトル付き）、複製、削除、並べ替え
- **その他**：元に戻す/やり直し（Ctrl+Z / Ctrl+Y）、複製（Ctrl+D）、コピー/貼り付け、最前面/最背面

## 保存とエクスポート

| 形式 | 出力先 |
|---|---|
| HTML上書き（Ctrl+S） | 元のHTMLファイル（上書き前に `.backups/` へ自動バックアップ） |
| HTML名前を付けて保存（Ctrl+Shift+S） | 選んだフォルダ・ファイル名。別フォルダの場合は使っている画像なども一緒にコピー |
| PDF・全ページ | `<スライド名>.pdf` |
| PDF・指定ページ | `<スライド名>_p1_3-5.pdf` |
| 画像・全ページ | `review/slide-NN.png`（既存の slide-*.png は置き換え）＋ `review/contact-sheet.png` |
| 画像・指定ページ | `review/slide-NN.png`（一覧画像は任意） |

PDF・画像はローカルの Chrome（なければ Edge）をヘッドレスで使って描画します。見つからない場合は環境変数 `CHROME_PATH` で場所を指定してください。書き出し時はページ送りボタンを非表示にします。
